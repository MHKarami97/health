# سلامت

اپلیکیشن وب PWA برای پیگیری روزانهٔ سلامت: تغذیه، فعالیت بدنی، چکاپ‌ها، داروها و عادت‌ها.

## اجرا

```bash
npm install
npm run dev
```

## ساخت

```bash
npm run build
npm run preview
```

## نکته مهم

این اپلیکیشن جایگزین توصیهٔ پزشک نیست. اعداد پیش‌فرض بر پایهٔ توصیه‌های عمومی WHO هستند و برای افراد دارای بیماری زمینه‌ای باید توسط پزشک تنظیم شوند.
