# سلامت

PWA فارسی برای پیگیری روزانهٔ سلامت (Vue 3 + TypeScript + Pinia + Tailwind 4).

## اجرا
```bash
npm install
npm run dev        # توسعه
npm run typecheck  # بررسی نوع‌ها
npm run build      # ساخت نسخهٔ تولید
```

## معماری
`domain` (قواعد خالص) ← `application` (store و سرویس‌ها) ← `infrastructure` (ذخیره‌سازی، رمز، اعلان، خروجی) ← `presentation` (Vue).

## محدودیت‌ها
- یادآورها فقط وقتی برنامه باز است کار می‌کنند (Push واقعی نیاز به سرور دارد).
- رمز عبور فقط UI را قفل می‌کند؛ داده‌ها رمزنگاری نمی‌شوند.
- «مشترک» یعنی چند پروفایل روی یک دستگاه؛ بین دو گوشی با فایل پشتیبان JSON.
